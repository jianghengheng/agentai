# Prisma 8 integration plan

**Goal:** Install Prisma 8 and make its PostgreSQL client available through NestJS dependency injection.

**Architecture:** Prisma 8 contract and CLI configuration describe the database. PrismaModule exports PrismaService, which owns the runtime database client. DATABASE_URL supplies the connection.

**Stack:** NestJS 12, TypeScript 6, Node.js 22, pnpm, Prisma 8, PostgreSQL.

## Tasks

- [x] Install `prisma@8.0.0-rc.27` as a development dependency and `@prisma/orm-postgres@8.0.0-rc.20`, `temporal-polyfill` and `dotenv` as runtime dependencies. Check the installed package declarations and CLI help for the exact Prisma 8 APIs.
- [x] Create `prisma.config.ts`, `src/prisma/contract.prisma`, `.env.example`, `.gitignore` and package scripts. Run `pnpm run prisma:generate` to validate contract authoring and emit JSON/types into `src/prisma`.
- [x] Add `src/prisma/db.ts`, `src/prisma/prisma.service.ts` and `src/prisma/prisma.module.ts`; import PrismaModule in `src/app.module.ts`, load environment variables and enable shutdown handling in `src/main.ts`. Run `pnpm run build` to verify ESM imports and contract packaging.
- [x] Update the existing e2e setup to isolate database access from greeting route tests. Document injection, environment setup and the installed CLI's database workflow in `README.md`.
- [x] Run Prisma contract emission, build, lint, unit tests and e2e tests. Use the user-provided Docker PostgreSQL database for integration verification after confirming it is empty. Initialize the contract, verify schema/marker consistency, and create/read a row in a rolled-back transaction.

The workspace is not a Git repository; execute in place and leave changes for review without commits.
